# Security Policy

## Supported versions

`swarmlab` is in early development. Security fixes are applied to the `main`
branch and the latest tagged release.

| Version | Supported |
|---------|-----------|
| 0.x     | ✅        |

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately. Do not
open a public issue.

- Open a [private security advisory](https://github.com/dmzhq/swarmlab/security/advisories/new)
  on this repository, or
- Email the maintainer with the subject `[swarmlab security]` to the address
  listed on the [profile page](https://github.com/dmzhq).

We aim to acknowledge reports within 5 business days and to coordinate
disclosure within 90 days of acknowledgement, unless the issue requires
upstream coordination.

## Out of scope

- Bugs that require an attacker to already have shell access to your machine.
- Social engineering of contributors or maintainers.
- Issues in third-party dependencies that are already publicly tracked
  upstream — please report those to the upstream project.

Thank you for helping keep `swarmlab` and its users safe.
